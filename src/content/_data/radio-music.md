# Radio Music Stations

Each section below is a meta-bind form bound to one entry in the `stations:`
array of the frontmatter above. Edit here in Reading View; the form writes
directly into the YAML so you never touch the raw structure by hand.

`station_band` and `station_freq` are pre-assigned per entry and shown in each
section heading so you know which dial coordinate the entry belongs to. Do
not edit those values directly.

If the entry is a **single-track embed** (one song, not the whole album), fill
in both `track_name` and `bandcamp_track_id` in addition to the parent
`bandcamp_album_id`. For an album-level embed, leave both blank.

The `tts_readout` is what the synthesized voice reads on the dial when the
station is tuned. Write it phonetically if the TTS engine mispronounces names
(for example, a band like "Boards of Canada" could be `Boords of Canada` so
the TTS gets it right). The shape is roughly:

> "Incoming organic signal... sender: \<artist\>... subject: \<album\>... click below to decrypt."

Reference for `genre` / `subgenre` values lives in `[[genre-mapping]]`. Open
that file side-by-side while filling out stations.
